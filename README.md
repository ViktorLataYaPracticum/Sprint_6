# Sprint_6 — Автотесты для сервиса «Яндекс.Самокат»

## Описание проекта
В проекте реализованы автотесты для учебного сервиса  
https://qa-scooter.praktikum-services.ru/

Тесты написаны в рамках Sprint 6 и покрывают:
- выпадающий список «Вопросы о важном»
- позитивный сценарий оформления заказа самоката
- переходы по логотипам «Самокат» и «Яндекс»

## Покрытые сценарии

### 1. Вопросы о важном
Проверяется, что:
- при клике на каждый вопрос раскрывается корректный текст ответа  
- для каждого вопроса используется отдельный тест  
- применяется параметризация

### 2. Заказ самоката (позитивный сценарий)
Проверяется полный флоу:
1. Нажатие кнопки «Заказать»  
   - в верхней части страницы  
   - в нижней части страницы
2. Заполнение формы заказа
3. Подтверждение заказа
4. Появление окна с сообщением об успешном создании заказа

Тест выполняется:
- с **двумя точками входа**
- с **двумя наборами тестовых данных**
- без дублирования сценариев

### 3. Проверка логотипов
Проверяется, что:
- при клике на логотип «Самокат» происходит переход на главную страницу сервиса
- при клике на логотип «Яндекс» в новом окне открывается главная страница Дзена
